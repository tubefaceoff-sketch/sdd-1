Design kit · componentes

Identidade visual da Pitang (cores, fontes e layout de pitang.com), em HTML + CSS puro: public/styles.css. Todo elemento da tela deve usar uma destas classes. Não escreva CSS novo.

Tokens

Títulos em Montserrat, texto em Inter (fallback: system-ui). Cartões raio 24px · inputs e botões 10px · badges pílula. Sombra 0 4px 20px rgba(45,45,45,.06).

Layout: cabeçalho + banner + conteúdo + rodapé

Esqueleto de toda tela, centralizado em 1200px como o site. O cabeçalho flutua com borda vermelha; o banner rosado traz o título da página; .bd-content é a área onde os cartões entram.

Botões

    
Ação principal: --primary (vermelho). Destaque alternativo: --accent (laranja). Secundária: --outline. Destrutiva (cancelar, remover): --danger. Confirmação positiva (check-in): --success. Em listas e tabelas, adicione --sm.

    












    

    

  


  
  

    
Badges de status

    
Status de uma pessoa ou item. Use sempre a mesma cor para o mesmo significado: verde = presente, laranja = confirmado/informativo, amarelo = em espera, vermelho = cancelado/erro.

Lista de pessoas

    
Para listas de inscritos: avatar com iniciais, nome e e-mail, badge e ações. Cores de avatar: padrão (vermelho), --green, --yellow, --orange. Com .bd-list__body--inline, nome e e-mail ficam na mesma linha ("Nome — e-mail").
